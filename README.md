# Paean — Apnea Trainer

Application web d'entraînement à l'apnée statique. Interface minimaliste, ambiance sous-marine.

## Modes

- **CO₂ Table** — apnée fixe, repos décroissant. Tolérance au CO₂.
- **O₂ Table** — apnée croissante, repos fixe. Tolérance à l'hypoxie.
- **Max Hold** — chronomètre libre pour le record personnel.
- **Custom Session** — configuration libre du protocole.
- **Lexique** — définitions des termes clés de l'apnée.

## Fonctionnalités

- Prévisualisation cycle par cycle avant chaque session
- Paramètres ajustables (nombre de cycles, durées d'apnée et de repos)
- Animation de respiration guidée
- Signaux sonores et vibrations aux transitions
- Résumé de session avec meilleur hold

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune dépendance, aucun serveur requis.

## Sécurité

Ne jamais pratiquer l'apnée seul, ni dans l'eau sans partenaire qualifié. Cette application est réservée à l'entraînement à sec.
